Welcome to **The Vanta House**, an ultra-sleek, pitch-black AMOLED architectural smart home experience. Designed with obsessive attention to luxury typography, buttery smooth squircle geometry, tactile 3D spatial models, and reactive ambient lighting, this project elevates connected living into an unforgettable digital showcase.

## 🚀 Live Website

Experience the fully interactive website live here:
https://thevantahouse.vercel.app

## 🎮 How to Control

- **Orbit & Inspect 3D Architecture:** Click and drag anywhere across the residence viewport or use arrow keys to rotate the spatial model in real-time.
- **Switch Ambient Atmospheres:** Tap the studio scene triggers (Dawn, Dusk, Midnight, Cyber) to watch the house dynamic lighting adapt instantly.
- **Explore Hardware:** Click on the interactive smart devices (Vanta Core, Vanta Secure, Vanta Glow, Vanta Vision) to view specifications, hardware breakdowns, and high-resolution details.
- **Interactive Form:** Test real-time client and server validation with responsive feedback, shake animations on errors, and instant request confirmation.
- **Keyboard Navigation:** Full accessibility support with tab indexing, dialog close escapes, and screen-reader compliant live region timers.

## ⚙️ Installation

### Prerequisites
- Node.js 22 or newer
- npm package manager

### Setup Instructions

1. Clone or navigate into the project directory:
```bash
git clone https://github.com/Y7XIFIED/thevantahouse.git
cd thevantahouse
```

2. Install dependencies:
```bash
npm install
```

3. Build the assets and client bundle:
```bash
npm run build
```

4. Launch the local dev server on a high-range port:
```bash
npm run dev
```

The application spins up locally at `http://127.0.0.1:48293`.

## 💻 Tech Stack

- **Three.js & WebGL:** Interactive 3D residence modeling, multi-layered mesh geometries, camera orbits, and custom lighting dials.
- **GSAP (GreenSock):** Editorial scroll animations, timeline choreographies, and hardware section transitions.
- **Vanilla JavaScript & Modern DOM:** Hyper-performant reactive controls, dialog traps, validation pipelines, and event handling.
- **Pure AMOLED CSS:** Pitch black `#000000` aesthetic, custom squircle radiuses, fluted glass blurs, and responsive fluid type.
- **Node.js & esbuild:** Lightning-fast static site compilation, asset optimization, and modular bundling.
- **Vercel Edge Platform:** Global edge distribution and production hosting.
